# Crochetti

A crochet pattern tracking app for Android.

Track your crochet projects row by row, count stitches, and manage your patterns all in one place.

## Features

- Create and manage crochet projects
- Row-by-row pattern instructions with stitch counter
- Built-in stitch glossary with custom stitch support
- QR code sharing to easily share patterns
